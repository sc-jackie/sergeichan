# Roadmap — Active Plans

This page shows the current roadmap for Jackie-OS and related projects. Plans are tracked here as dated initiatives; shipped items move to the **Shipped** section. The source of truth lives in code repos' `plans/roadmap-index.md` files and this file for Jackie-OS itself.

**Key principle:** forward work lives in this file while active; upon ship, the plan is documented in the ledger, the dated plan file is deleted from git (`git rm`), and any durable decision is captured in the decisions log.

See also: [Ideas Backlog](/jackie-os/docs/ideas-backlog) (speculative items) · [Decisions Log](/jackie-os/docs/decisions) (shipped rationale)
