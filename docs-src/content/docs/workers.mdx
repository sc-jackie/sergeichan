## The dispatch pipeline

<Steps>
  <Step>
    <h4>Issue</h4>
    <p>bug, feature, or goal in Linear</p>
  </Step>
  <Step>
    <h4>Buzz (optional)</h4>
    <p>discuss with personalities in channel / project</p>
  </Step>
  <Step>
    <h4>fleet</h4>
    <p>operator or Hermes claims a run record and kicks the cloud factory</p>
  </Step>
  <Step>
    <h4>Cloud run</h4>
    <p>Cursor Cloud, Claude web (`--cloud`), or Codex cloud</p>
  </Step>
  <Step>
    <h4>PR / doc</h4>
    <p>tested PR with <code>Fixes &#60;ISSUE-ID></code> or Linear doc → In Review</p>
  </Step>
  <Step>
    <h4>Merge</h4>
    <p>human merges — agents never merge or push default branches</p>
  </Step>
</Steps>

**merge → merge-poll posts Linear status → project-sync updates vault Status + hot.md**
