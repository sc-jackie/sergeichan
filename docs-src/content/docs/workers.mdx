# Current flow

Sergei's primary interactive desk is **bb**. **Hermes Agent** by Nous Research runs the always-on COO loop: briefs, journal capture, Read Later, knowledge work, ops, and scheduling. Bounded code, design, and research tasks go to temporary **Cursor ACP workers**. **Linear** tracks the projects.

## Interaction flow

1. Sergei interacts via **bb** (his primary interactive desk).
2. **Hermes Agent** manages the daily rhythm and maintains the vault and project status.
3. Bounded code, design, and research work can go to temporary **Cursor ACP workers**.
4. Workers develop in isolated worktrees, open pull requests, and report progress back to the issue.
5. Upon merge, Hermes Agent updates the vault and project status notes.
6. The vault serves as the single source of truth for knowledge and skills.
