    Jackie OS — how to install and use it¶

    A shareable guide for setting up a personal knowledge OS that keeps your notes, projects, and code repos aligned — with AI as your COO, not your memory.

    For your friend (5-minute read)¶

    What it is: Jackie OS is a git-backed Obsidian vault (your second brain) plus a small folder of AI "skills" (markdown playbooks) that any AI agent can run. You stay CEO — the agent is your COO and CTO: morning briefs, project status sync, research filing, and writing/shipping code. It does not rewrite your journal.

    No server required. Open this folder in Claude Code, Cursor, or Codex and that tool becomes a Jackie OS agent — it auto-reads the rules and runs the skills; say wrap up and it syncs the vault. Hermes (an always-on agent on a VPS) is optional — it just runs the loop on a schedule while you sleep.

    The problem it solves: You code in Cursor; Claude in a separate chat has no idea what you shipped yesterday. Notes and repos drift apart. Every session starts cold.

    The minimum loop (this is the whole trick):

    1. Registry — one table maps each project to its vault note, code repo, or status file
    2. project-sync — pulls git + status files into vault ## Status (runs at session end and inside the morning brief)
    3. hot.md — a ~500-word cache agents read first so they know current focus without re-reading everything
    4. Session end — say "wrap up"; agent syncs, updates hot, commits the vault

    Before / after:

    Before After
    "What was I working on?" every morning Yesterday's brief + hot.md
    Code and notes disagree One sync loop, one registry
    Fixes lost in one repo's chat history docs/solutions/ + cross-project index

    Three setup tiers — pick what fits:

    Tier You get Time
    A — Vault PM Obsidian + vault + registry + manual sync ~30 min
    B — Vault + code Tier A + one code repo with bridge doc ~1 h
    C — Full loop Tier B + always-on automation (VPS Hermes runs the morning stack on a schedule) + merge-poll for intraday code→vault sync ~2 h + ongoing

    Send your friend: this section + Quick install if they're technical, or Tier A only if they just want notes + AI briefs.

    What it is (detail)¶

    Jackie OS is a git-backed Obsidian vault plus a small skill system (System/skills/). Claude (Cowork, Cursor, or Claude Code) reads the same rules every session:

    • Vault — project notes, journals, briefs, theses, clippings
    • Skills — repeatable workflows (morning brief, project sync, telegram-sweep, weekly review)
    • Project registry — maps each project to its code repo and/or STATUS.md
    • hot.md — a ~500-word cache agents read first (current focus, not history)

    You stay CEO. The agent is COO: briefs, status sync, research filing — not rewriting your journal.

    What problem it solves¶

    Without Jackie OS With Jackie OS
    You code in Cursor; Claude in chat has no idea project-sync pulls git into vault ## Status
    Notes and repos drift apart One registry, one sync loop
    Every session starts cold hot.md + yesterday's brief
    Fixes stay in one repo docs/solutions/ + cross-project index

    Prerequisites¶

    Tool Role
    Obsidian Read/write vault (optional but ideal for daily notes)
    Git Version the vault and code repos
    Claude Code / Cursor / Codex Open the folder → it becomes a Jackie OS agent (wrap up sync at session end)
    GitHub Remote for vault + code repos
    VPS + Hermes (optional) Always-on automation — runs the morning stack on a schedule while your Mac is off
    Google Calendar + Gmail (optional) Morning brief connectors

    No Cursor automations — all were removed 2026-06-17; Cursor is just an IDE. Code→vault sync runs via the 07:30 morning-brief (authoritative; reads merges from git log) plus a merge-poll GitHub Action in jackie-os (registry-driven, ~2h, read-only) for intraday updates. PR review on demand: /review-bugbot or /review-security in Cursor.

    Quick install (≈1 hour)¶

    1. Clone and open¶

    git clone git@github.com:YOUR_USER/jackie-os.git ~/jackie-os
cd ~/jackie-os

    Open ~/jackie-os/Vault/ in Obsidian. Read order for any agent:

    1. Vault/hot.md
    2. Vault/CLAUDE.md
    3. Vault/Home.md
    4. Project note for the task

    Branch note: jackie-os uses master. Code repos typically use main. Git on origin/<branch> is code truth; the vault is PM truth.

    2. Copy the skill loop¶

    Jackie OS ships skills in System/skills/. You need thin scheduled tasks in Claude Cowork that only say: "Read System/skills/X.md and follow it exactly."

    Time Skill Output
    07:30 morning-brief sweep → sync → brief → Persik → linking → * links.md
    hourly journal-capture Persik DMs → daily note
    Sun 18:00 weekly-review compound + Vault/Briefs/YYYY-Www brief.md

    Cowork space must include vault + code folders: ~/Jackie-OS and ~/dev (see OPERATOR.md · skills/vault-rhythm/SKILL.md). Thin pointers: ~/Claude/Scheduled/*/SKILL.md → System/skills/.

    Retired Cowork crons: jackie-os-telegram-sweep, jackie-os-daily-linking, jackie-os-vault-index (on demand: vault index).

    3. Register your projects¶

    New git code repo: say register project or new code project in any Jackie-OS session — agent runs System/skills/new-code-project.md (registry, vault, bridge, learnings). Then complete the Cursor UI checklist in skill § B (automations are not automatic).

    Manual fallback — edit System/project-registry.md — one row per project:

    Source type When to use
    git Code repo with GitHub remote
    status-file Folder project with Projects/MyThing/STATUS.md
    vault Dormant idea; vault note only

    Add a vault note per project (Vault/My Project.md) with a ## Status section.

    4. Bridge each code repo¶

    In every code repo, add docs/JACKIE-OS.md (copy from System/templates/JACKIE-OS-bridge.md) and a line in that repo's CLAUDE.md:

    After coding: push + PR merge (merge-poll Action + 07:30 brief sync the vault) or from Jackie OS say wrap up for direct pushes / vault-only work.

    5. Code repos (siblings of Jackie-OS)¶

    Code repos live outside Jackie-OS in a sibling tree (~/dev/), never nested inside it — keeps the vault git clean and avoids gitignore hacks. Pattern:

    mkdir -p ~/dev
git clone git@github.com:YOUR_USER/my-app.git ~/dev/my-app

    Register the path in project-registry.md as a git row (~/dev/my-app/). The vault holds knowledge about the repo in a project note; the code stays in ~/dev/. Commit code changes inside ~/dev/my-app/ separately from Jackie-OS vault commits.

    6. Secrets (optional)¶

    Telegram sweep + morning brief delivery: .secrets/telegram.env (gitignored). See System/skills/telegram-sweep.md and System/skills/morning-brief.md.

    Telegram delivery: .secrets/telegram.env — see System/skills/morning-brief.md. The delivery scripts live in the repo at System/coo/ (e.g. brief-deliver-via-cron.py, brief-to-telegram.py) and are symlinked onto the VPS at ~/.hermes/scripts/ via System/scripts/hermes-vps-link-scripts.sh.

    Cowork network allowlist (Settings → Capabilities): api.telegram.org, and your Newfin API host for coo-push.

    Daily workflow¶

    Evening / after vault work          Morning (automatic)
        │                                │
        ▼                                ▼
  "wrap up" (vault only)          07:30 morning-brief
        │                         (sweep + sync + brief
        ├─ project-sync            + Telegram DM + coo-cache + linking)
        └─ git commit vault

  PR merge on code repo → merge-poll Action syncs vault intraday; 07:30 brief is authoritative

    Rule: Git on origin/<branch> is code truth (main for apps, master for jackie-os). The vault is PM truth. Push before sync.

    Cloud / Cursor agents¶

    Cursor cloud agents often clone only Jackie-OS — not your external code repos or gitignored nested folders. project-sync skips missing clones and logs a warning; it does not fail the whole sync. For full sync, run wrap up or morning brief on a machine where registry paths exist locally (your Mac via Cowork is the typical source of truth).

    Global agent skills (optional, Tier C)¶

    One command (Jackie-OS clone on the Mac):

    bash ~/Jackie-OS/System/tools/install-global-skills.sh

    Installs real-file copies of global skills (previously Jackie-OS owned: jos-design-ui, jos-plan, jos-plan, jos-product-eval, agent-reach, jos-performance-check) + selective upstream (grill-for-unknowns + grill-me alias stub, teach, last30days, 3× CE) into ~/.agents/skills/. Do not bulk-install the CE plugin. Subagent map: cursor-rules.md.

    Ad-hoc web reads (Exa + OpenCLI): used by research.md § Quick scout. Install mcporter + Exa:

    npm install -g mcporter && mcporter config add exa https://mcp.exa.ai/mcp

    For OpenCLI (Instagram/Twitter/Reddit reads), install agent-reach separately — it is no longer bundled with Jackie-OS:

    pipx install https://github.com/Panniantong/Agent-Reach/archive/main.zip
agent-reach install --env=auto   # EU/US channels only; CN channels archived

    Codebase memory MCP (structural code intelligence — newfin + rodyna):

    curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash -s -- --skip-config
codebase-memory-mcp config set auto_index true

    Add to ~/.cursor/mcp.json (alongside headroom):

    "codebase-memory": {
  "command": "/Users/jackie/.local/bin/codebase-memory-mcp",
  "args": []
}

    Restart Cursor. Routing: System/skills/codebase-memory.md.

    After a non-trivial fix in a code repo:

    1. jos-compound → writes docs/solutions/ in that repo
    2. Add one index row in Jackie OS Vault/Agent-Learnings/ (never copy the full doc)
    3. jos-compound is in-session (not automated); the merge-poll Action + 07:30 morning-brief keep the vault in sync (no Cursor automation — all removed 2026-06-17)

    Troubleshooting¶

    Symptom Fix
    Brief missing yesterday's code work Push to GitHub, then sync projects (or wait for 07:30 brief)
    Brief says old state (e.g. "behind 107") but you already pulled Evening project-sync updated vault but not brief body — check brief ## Since sync or wait for tomorrow's 07:30 brief
    Agent overwrote my journal Hard rule: never edit inside Vault/YYYY-MM-DD.md journal bodies
    Two agents collided on a file git status first; multi-writer discipline in root CLAUDE.md
    Cowork task ran wrong logic Task must be a thin pointer to System/skills/, not inline instructions
    project-sync skipped my code repo Clone missing at registry path — create clone or update path in project-registry.md
