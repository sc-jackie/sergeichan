    Skill map¶

    Full system map (skills + scripts, what + where-used): CATALOG.md — the newcomer entry point.

    Sergei (operator): OPERATOR.md — one-page cheat sheet; what runs automatically vs what you still say.

    Every skill is a markdown file in System/skills/ — vault-owned, git-versioned, tool-agnostic. Cowork scheduled tasks are thin pointers to these files; the files are the source of truth. New skills follow skills/skill-builder.md and get registered here.

    Naming convention (2026-07-10): everything in System/skills/ is owned by definition — no prefix needed (and renames would break wikilinks + VPS scheduled-task pointers). The jos- prefix marks owned skills that are also symlinked into the shared global tree ~/.agents/skills/, where they sit next to upstream installs: jos-* = ours, battle-tested; unprefixed = upstream. Exception: wrap-up predates the prefix and is grandfathered unprefixed — it's referenced by dozens of docs, hooks, and habits, and still triggers on "wrap up" text; rename cost > consistency win. Hermes runs nothing outside this repo — skill playbooks live in System/skills/, executable scripts in System/{coo,capture,ops,periodic,work,lib}, symlinked onto the VPS.

    Compound Engineering¶

    CE plugin skills retired 2026-07-10 — merged into owned jos-compound (capture + refresh modes) and jos-plan. Do not install the compound-engineering plugin.

    jos-compound (global skill): After a non-trivial root-cause fix, writes the repo's docs/solutions/ doc + Vault/Agent-Learnings/ index row (/jos-compound). Refresh mode audits stale learnings (/jos-compound refresh). Run in-session, not automated.

    Full inventory: ~/AGENTS.md. CE plugin: off — do not install. All others above are on. Rules: cursor-rules.md. PR review: /review-bugbot, /review-security.
