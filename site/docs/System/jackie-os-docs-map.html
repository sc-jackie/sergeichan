Three Automation Layers

Layer Jobs Schedule
Hermes Agent Cron morning-brief · journal-capture · telegram-sweep · trade-digest 07:30 · hourly · 07:00 · 07:10
OS Crontab autodeploy · merge-poll · healthcheck · intel-weekly · cbm-index */2 · ~2h · 08:00 · Sun · Sun
Mac Weekly weekly-review (only remaining Cowork schedule) Sun 18:00

A job must never live in multiple layers. VPS owns everything; Mac weekly-review is the last holdover. On-demand: research <topic> skill (no auto-watchlist).
