    period-review¶

    Purpose: the fractal review protocol — coach brief (Phase A) + coach session → Sergei note (Phase B) for week, month, and year closes. Monthly and yearly horizons live entirely in this file; weekly Phase A lives in weekly-review (scheduled, carries system steps). Trigger: monthly review / monthly coaching review / coaching review · yearly review (morning-brief nudges: month-end 📋; Jan 1–7 for prior year) · imported by weekly-review for Phase B. Role: Coach. Output: Vault/Briefs/…brief.md (Phase A) · Sergei period note at vault root (Phase B).

    Folders: Jackie-OS (+ ~/dev/ when work/trading context matters).

    Gate — which phase runs¶

    Check Action
    AI brief missing Run Phase A for that horizon (write brief, commit, stop)
    Brief exists, Sergei note missing Run Phase B below
    Both exist Report done; offer to append Sergei note section only if Sergei asks

    Slugs + done signals: week YYYY-Www.md · month YYYY-Mmm.md (e.g. 2026-M06, not 2026-06) · year YYYY.md. Sergei note existing at vault root = done for morning-brief nudges.

    Phase A — Monthly brief¶

    Read first: coaching, Vault/hot.md, [[About me]], [[Theses]], [[Coaching]], latest [[Self-portraits]]. Optional: latest psychological synthesis (pattern names only). Month window: previous calendar month unless stated in header.

    Inputs (cap ~50 full bodies): dailies in month; Briefs/ daily briefs; Briefs/YYYY-Www brief.md overlapping weeks; [[Trading playbook]]; project Status + git since month start; prior Briefs/YYYY-Mmm brief.md for delta. Skip #private.

    Write Vault/Briefs/YYYY-Mmm brief.md:

    ---
categories:
  - "[[Briefs]]"
  - "[[Coaching]]"
created: YYYY-MM-DD
month: YYYY-Mmm
---

# YYYY-Mmm — Monthly brief

*Coach's lens on [month]. Sergei owns the conclusions — evidence + questions, not diagnosis.*

## Executive summary
## How you felt
## How you thought
## Trading & money psychology
## Work & building
## Patterns (month-scale)
## Theses health (monthly depth)
## Delta from last month
## Self-portrait & About me
## Questions for Sergei
## One experiment (next month)

    Commit: Monthly brief YYYY-Mmm. Stop — tell Sergei: read [[YYYY-Mmm brief]], reply monthly review when ready. Persik: vault-only default (skip coo-push unless Sergei opts in).

    Phase A — Yearly brief¶

    Read first: same stack as monthly. Inputs: all YYYY-Mmm / YYYY-Www briefs and Sergei notes in year; dailies (cap ~50); monthly briefs; [[Trading playbook]]; project Status arc. Skip #private.

## Executive summary
## Emotional arc
## Work & building
## Trading & money psychology
## Thesis evolution
## Self-portrait recommendation
## Questions for Sergei

    Commit: Yearly brief YYYY. Stop — read [[YYYY brief]], reply yearly review when ready.

    Phase B — session protocol (all horizons)¶

    Read first: coaching stance, Vault/hot.md, Vault/CLAUDE.md.

    1. Confirm read — Sergei has read [[YYYY-Www brief]] / [[YYYY-Mmm brief]] / [[YYYY brief]]. If not, stop: point at brief path.
    2. Coach session — one question at a time; mechanism not mood-only; Sergei owns conclusions. Use horizon script below.
    3. Co-write Sergei note — draft from session; Sergei approves/edits; save from template (Weekly note / Monthly note / Yearly review).
    4. Cross-link — note wikilinks [[… brief]]; append one line to brief footer only: *Sergei's read → [[YYYY-Www]]* (never rewrite brief body).
    5. Commit — Weekly note YYYY-Www / Monthly note YYYY-Mmm / Yearly note YYYY.
    6. Index — add row to [[Reviews]] if missing (monthly + yearly also update [[Coaching]] index).

    Sergei note sections (W/M/Y identical)¶

    • At a glance — one paragraph, your voice
    • What mattered — 3–7 bullets
    • My read vs the brief — where you agree, disagree, or add what the brief missed
    • Carry forward — one experiment or intention

    Session scripts (coach voice)¶

    Weekly (15–25 min): (1) reaction to brief — what landed, what didn't (2) energy arc / one tension (3) one experiment for next week (4) draft At a glance together.

    Monthly (45–60 min): felt/thought/trading/work depth — same inquiry as monthly brief sections; evidence from dailies only.

    Yearly (60–90 min): era shift, thesis evolution, portrait gate; optional 40-Q prompts from Yearly review template.

    Rules¶

    • Never edit daily journal bodies or Journals/Archive/Journal 20XX.md compilations; yearly note is additive — never merge into the archive compilation.
    • Period notes may be created and appended (co-written sections after approval) — see Vault/CLAUDE.md exception.
    • Skip #private / private frontmatter entirely.
    • COO content (projects, system health) stays in the brief, not the dialogue.
    • Wikilinks only; no clinical diagnosis; no live portfolio numbers from chat.
