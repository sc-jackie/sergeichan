    DOCS — the master index¶

    Public site: jackieos.vercel.app — landing (winner of 10 options) + docs (VPS IP + email scrubbed at build; publish: System/tools/publish-site.sh --prod). Local: bash System/tools/docs-site.sh serve → 127.0.0.1:8123. Config: docs-site/mkdocs.yml. (jackie-os-docs.vercel.app is the same deployment's legacy domain; jackie-os.vercel.app belongs to an unrelated team.)

    The rule this page exists for (docs-first): before building anything new — a skill, script, worker, connector, automation — check this index for prior art. Something similar probably exists; extend it instead of adding a parallel thing. And when you ship something new, update the owning doc in the same commit (ownership map below).     Workers — autonomous agents¶

    Documented in CONCEPTS.md § Linear integration + autonomous agents; sync contract in ~/dev/bunit/docs/linear-workflow.md.

    Worker Runs on Scope Dispatch
    Hermes (Claude Agent SDK) VPS hermes@your-vps-host General-purpose agent: morning stack, journal, sync, ops, research; can launch supervised Claude Code sessions. Not the Linear coding worker. 3-layer cron + Telegram/CLI ask
    Cyrus (Claude Code) Hermes VPS The Linear → Claude Code worker: eligible issues → isolated worktree → PR → progress on the issue (B-Unit, Newfin, Rodyna) Linear agent-session events (assign/comment on issue)
    Codex (ChatGPT) GitHub CI same repos, PR review + build lane Linear labels / CI
    Interactive agents (Claude Code, Cursor, Codex CLI) Mac anything, per CLAUDE.md roles (COO default, CTO in ~/dev/*) Sergei, per session

    Per-repo routing table: ~/dev/<repo>/AGENTS.md § Choose the right worker (added 2026-07-10).

    Sergei is PO/PM: refines + approves in Linear (needs-refinement → needs-approval gates), orchestrates workers; merge-poll auto-posts Linear project status on batched merges.

    Skill naming¶

    jos- prefix = owned + battle-tested, lives in ~/.agents/skills/ (jos-plan, jos-compound, jos-design-ui, jos-product-eval, jos-performance-check). Unprefixed global = upstream (grill-for-unknowns, last30days, teach, visual-explainer). Repo skills (System/skills/) carry no prefix — everything there is owned by definition. Full convention: System/SKILLS.md § Naming.
