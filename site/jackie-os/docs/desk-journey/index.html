I tried five desks for agent work

Cyrus, Linear, Buzz, bb, then Cursor — what I kept and what I killed.

I spent two months changing how I sit with AI agents. I did not find a better model. I found a smaller office.

This page is the public record. The live contract is Operator desk. I kept the graves so the next agent does not revive a logo.

What I use now

Cursor on the laptop or the PC. Tailscale between Mac, PC, and the VPS. Hermes for morning briefs, journal, merge-poll, Telegram — not coding agents. Grok in another window for thinking. Linear as a list.

bb is not in active use. I do not start work there.

The tries

1. A folder and a VPS

Open ~/Jackie-OS in Claude Code, Cursor, or Codex. Hermes on a Hetzner cx23 for the schedule.

This still works. Everything after this was extra surface.

2. Cyrus + Linear — a company in the tracker

Named agents: Fablio, Cursorio, Codexio, Cyrusio, Marketio, Scriptio. Linear Delegate. A cloud factory. Host ceiling 5, then 6, on 4 GB of RAM.

It looked like an org chart. It ran like a second job: heal, steer, Inbox, swapfile. The VPS thrashed. I was managing agents instead of shipping.

Killed 2026-08-05.

3. Buzz — two desks

Buzz as the cockpit. Hermes as lead. Nests on the Mac. The factory still underneath.

Two places that could be true. Cron noise. I cut it in two days (2026-08-07).

4. bb — one remote UI I stopped opening

bb was the honest version: one browser desk, any machine, custom plugins in git.

I used it. Then I stopped. The docs did not notice. Every new session sent me to evegelin.getbb.app.

Killed as the default desk 2026-08-17. The tree stays as history.

5. Cursor + Tailscale + Hermes + Grok

One IDE I already have open. A mesh so the PC and the VPS are on the same network. A small box that only runs the loop. A chat window that is not allowed to write git.

That is the desk.

Harnesses I still keep as tools

Claude Code. Codex. Cursor Agent / ACP. Pi and Prime with Ollama on the Home PC. eve and skills.sh as patterns.

I do not make them the office.

What I would not have believed in June

  1. A named fleet is headcount.
  2. Linear should not wake anyone.
  3. A 4 GB VPS can run a brief. It cannot run six agents.
  4. Two interactive desks means neither is true.
  5. Parallel chat is useful if it cannot write truth.
  6. Do not delete the history. The next agent will revive whatever the docs still call primary.
