Four questions this site answers

1. What is this system?

Start with what Jackie-OS does — the plain-English walkthrough. Then the system map (one page, top to bottom: you → vault/skills → Hermes → workers → back to you) and the vocabulary.

2. What do I do?

The cheat-sheet: the ~5 things you say ("wrap up", "grill me", "research X", reviews) — everything else is automatic. Plus: closing a session, fixing the VPS, adding a project.

3. What runs by itself?

Every scheduled job on one page — the 07:00–07:30 morning stack, hourly journal, merge-poll, autodeploy — and which project syncs from where.

4. What's the plan?

The roadmap (active plans, shipped ledger), the ideas backlog, and the decisions log — the durable why.

Looking for something specific? Use search (top bar) — every skill, script, and doc is indexed. Or start from the master index.

The one rule: before building anything new, check the master index for prior art. When something ships, its doc updates in the same commit — so this site is always current.

This site renders the repo's markdown directly (docs-site/, symlinked — no copies). Serve: bash System/tools/docs-site.sh serve → 127.0.0.1:8123.
