01

What it is

One system of record for a genuinely mixed book: liquid and vesting crypto, futures, real estate in two countries, private deals, receivables, cash.

Around that record: an API-first server, a web dashboard, a live trading desk, and a Telegram agent scoped to the household.

02

Why it exists

Every finance app tracks a slice. None could hold the whole book without lying somewhere — vesting counted as cash, a transfer counted as spending, property with no place at all.

And numbers without judgment are noise. The advisor had to read the actual state and answer in dollars and percent — not market clichés.

“Balance isn’t liquidity. A transfer isn’t spending. A bot shouldn’t become a second ledger.”

03

What it solves

  1. One truthful net-worth line

    Every asset class, every currency — with liquid and locked kept apart, so the number you can move is never inflated.

  2. An advisor bound to the real payload

    The model reasons over a scoped snapshot of the actual book. Recommendations arrive with numbers, never generic advice.

  3. Household access with hard scoping

    The owner sees everything. Family members see only their view — enforced before the model ever runs.

  4. Read-only by design

    It can describe a move. It can never execute one. No keys, no orders, no transfers.

04

A day with it

  • 07:10

    The digest arrives

    Overnight moves, positions, and anything that needs attention — pushed to Telegram before the day starts.

  • Midday

    Spending books itself

    Card and wallet activity lands in Cashflow on schedule. Transfers stay transfers; spending stays spending.

  • Desk

    Risk before the trade

    IBKR and Hyperliquid on one desk, beside the whole book — so a new position is sized against everything, not one account.

  • Evening

    Ask, don’t assemble

    “How did we do this week?” Persik answers from the same book the dashboard reads. No spreadsheet archaeology.

05

Architecture

Five layers, one truth. Integrations feed the server; the server owns the math; every surface reads the same scoped state.

  1. Integrations exchanges · wallets · banks · brokers
  2. Server Express API · net-worth math · role scoping
  3. Supabase Postgres · auth · the system of record
  4. Web PWA portfolio · cashflow · trading desk
  5. Persik Telegram agent · household-scoped answers

The shared workspace owns the net-worth math. The Telegram agent gets role-scoped views of the same truth — never its own copy.

06

Current state

Live in production, used daily by the household. Feature development is parked while an agent loop works the backlog — the system maintains itself more than it gets maintained.

  • Live
  • Daily use
  • Agent loop
  • Read-only by design

One book. No lies in it.
